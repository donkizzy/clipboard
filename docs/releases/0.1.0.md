# Clipboard 0.1.0

Initial release for macOS 14 Sonoma and later. Press **⌘⇧V** to search clipboard history, preview a selection with Space, or pin it with **⌘P**. Use **Return** to copy an item and **⌘Return** to paste back into the previous app.

- Search text, code, URLs, images and file references in card or list view.
- Set a history limit, exclude apps, and pause capture from the menu bar.
- Link titles and icons are fetched by default. Turn off **Fetch link titles and icons** in Privacy settings to keep copied links from triggering preview requests.

The universal build includes Apple silicon and Intel executables. Paste-back requires Accessibility permission. Local candidate archives have the suffix `-local-rc.zip` and use an ad-hoc signature.
